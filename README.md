# Chatly — Real-time Chat Rooms

Chatly is a real-time chat app built with Socket.io. Pick a username and a room, and chat live with everyone in it.

## Features

- Named chat rooms with join / leave announcements
- Live user list per room
- Share your location as a Google Maps link
- Profanity filter on outgoing messages

## Stack

Node.js · Express · Socket.io · bad-words · vanilla JS front end

## Run locally

```bash
git clone https://github.com/Ahmed-Abdelhafez98/Chatly.git
cd Chatly
npm install
npm run dev
```

Open `http://localhost:3000`, enter a display name and room, and open a second tab to chat with yourself.
